# Nestediff – CodeMentor AI Frontend

## Prerequisites
- Node.js LTS
- npm
- Backend running at http://localhost:8080

## Run
Open Command Prompt in this folder:

    npm install
    npm run dev

Then open the URL shown by Vite, normally http://localhost:5173

## Notes
The UI contains a demo fallback. If the backend is not running, clicking Analyze Code still shows sample mentor feedback so the screens can be demonstrated. Once the Spring Boot backend is running, the frontend calls the backend APIs.
